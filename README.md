# 🔮 Descubra seu Signo

Aplicação web desenvolvida em PHP que identifica o signo zodiacal do usuário com base em sua data de nascimento. O projeto utiliza um arquivo XML para armazenar os dados dos signos e Bootstrap para construir uma interface responsiva.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática acadêmica para aplicar conceitos de desenvolvimento web, integração entre PHP e XML, formulários HTML e estilização com Bootstrap e CSS.

## ✨ Funcionalidades

- Formulário para informar a data de nascimento.
- Identificação do signo zodiacal correspondente.
- Consulta dos dados armazenados em XML.
- Exibição do nome, período e descrição do signo.
- Interface responsiva com Bootstrap.
- Navegação entre a página inicial e a página de resultado.

## 🛠️ Tecnologias utilizadas

- **PHP** — processamento dos dados e identificação do signo.
- **HTML5** — estrutura das páginas.
- **CSS3** — estilização personalizada.
- **Bootstrap 5** — layout responsivo e componentes visuais.
- **XML** — armazenamento das informações dos signos.
- **Apache / XAMPP** — ambiente de execução local.
- **Git e GitHub** — versionamento e hospedagem do código-fonte.

## ⚙️ Como executar o projeto

### Pré-requisitos

- [XAMPP](https://www.apachefriends.org/)
- [Visual Studio Code](https://code.visualstudio.com/)
- Navegador web

### Instalação

1. Clone este repositório ou baixe os arquivos do projeto.
2. Coloque a pasta do projeto no diretório `htdocs` do XAMPP.
3. Abra o painel de controle do XAMPP e inicie o Apache.
4. Acesse o projeto pelo navegador:

```text
http://localhost/Project/
```

5. Informe sua data de nascimento e clique em **Descobrir meu signo**.
